Integrated download buttons

Custom filename schemes

[Title]Media or post title, for example Title.
[@Poster]Uploader, channel, or post author, for example @user.
[Source]Site token, for example x.com, youtube, or reddit.
[Index]Gallery item number, for example 01, 02.
[Start]Video range start time for filenames, for example 0-15.
[End]Video range end time for filenames, for example 1-30.
[Start Time]Alias for [Start].
[End Time]Alias for [End].
Examples[Title] -- [@Poster] -- [Source] becomes Title -- @user -- x.com. Gallery downloads append the item index when needed.
