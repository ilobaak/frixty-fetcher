Datetime token format

Custom datetime formats can use [yyyy], [yy], [MM], [dd], [hh], [mm], [ss], [ms], [tz], and [tzSafe]. [Datetime] uses your browser's current local date, time, and time zone when the filename is generated. Example: "[yyyy]-[MM]-[dd]T[hh].[mm]" becomes "2026-08-18T17.49".

Time token format

Custom time formats can use [hh], [mm], [ss], and [ms]. This format is used by filename tokens that contain a video timestamp, such as [Video Start Time], [Video End Time], and [Video Frame Time]. Example: "[hh]-[mm]-[ss]" becomes "01-02-03".

Custom filename schemes

[Title]Media or post title, for example "Midnight Train Review".
[@Poster]Uploader, channel, or post author, for example "@riverclips".
[Source]Site token, for example "x.com", "youtube", or "reddit".
[Index]Gallery item number. Example: "[Title] -- [@Poster] -- [Source] - [Index]" becomes "Midnight Train Review -- @riverclips -- reddit - 01".
[Datetime]Current local browser date, time, and time zone using the selected datetime format. Example: "2026-08-18T17.49.04.125-04.00".
[yyyy] [yy] [MM] [dd]Current local year, short year, month, and day. Example: "[yyyy]-[MM]-[dd]" becomes "2026-08-18".
[hh] [mm] [ss] [ms]Current local hour, minute, second, and millisecond. Example: "[hh].[mm].[ss].[ms]" becomes "17.49.04.125".
[tz] [tzSafe]Current local UTC offset. [tz] is ISO-style, for example "-04:00". [tzSafe] avoids filename colons, for example "-04.00".
[Video Start Time]Video range start using the selected time format. Example: "00.00.15.250".
[Video End Time]Video range end using the selected time format. Example: "00.01.30.000".
[Video Frame Time]Selected frame timestamp using the selected time format. Example: "00.00.42.500".
[Video Frame Number]Frame number when the source reports enough timing detail. Example: "FRAME-[Video Frame Number]" becomes "FRAME-1260". If unavailable, it is left blank.
Examples
Example "[Title] -- [@Poster] -- [Source]" Becomes "Midnight Train Review -- @riverclips -- x.com"
Example "[Title] -- [yyyy]-[MM]-[dd]T[hh].[mm].[ss].[ms][tzSafe]" Becomes "Midnight Train Review -- 2026-08-18T17.49.04.125-04.00"
Example "[Title] -- [@Poster] -- [Source] - [Index]" Becomes "Midnight Train Review -- @riverclips -- reddit - 01"
Example "[Title] -- [@Poster] -- S([Video Start Time]) -- E([Video End Time]) -- [Source]" Becomes "Rainy Trail Highlights -- @trailcam -- S(00.00.10.000) -- E(00.00.45.000) -- youtube"
